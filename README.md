# danielivanovz/tap

Homebrew formulae for my tools.

```sh
brew install danielivanovz/tap/mysessions
```

| Formula | Description |
| --- | --- |
| [`mysessions`](https://github.com/danielivanovz/mysessions) | Reopen terminal coding-agent sessions in tabs after a restart (macOS) |

Formulae build from source, so the first install also fetches Rust as a
build dependency.
